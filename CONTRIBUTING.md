# Contribuir al portafolio

- Mantén cada cambio enfocado y explica el problema visual o de contenido que resuelve.
- No agregues datos personales, imágenes o testimonios sin autorización.
- Revisa todas las páginas si cambias navegación, estilos globales o pie.
- Adjunta capturas de móvil y escritorio para cambios visuales.
- Verifica teclado, foco, contraste, zoom, enlaces e imágenes antes de solicitar revisión.
- No incluyas refactors o rediseños ajenos al objetivo del pull request.
