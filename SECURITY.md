# Política de seguridad

No publiques vulnerabilidades, datos personales ni pruebas de concepto explotables en un issue público.

Usa **Report a vulnerability** en la pestaña Security del repositorio para abrir un GitHub Security Advisory privado. Describe la página o recurso afectado, el impacto y los pasos mínimos de reproducción.

Son de especial interés la exposición de datos personales, formularios o enlaces manipulables, inclusión de scripts externos, dependencias de terceros, configuración del hosting y filtración de credenciales.

No accedas a cuentas o datos ajenos, no interrumpas el sitio y limita la prueba al impacto mínimo necesario.
