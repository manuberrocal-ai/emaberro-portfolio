# emaberro-portfolio

Portafolio web estático construido con HTML y CSS.

## Estructura

- `index.html`: portada.
- `about.html`: presentación.
- `services.html`: servicios.
- `portfolio.html`: trabajos o proyectos.
- `contact.html`: contacto.
- `style.css`: estilos compartidos.
- `*.png`: recursos visuales.

## Uso local

Puede abrirse `index.html` directamente en un navegador. Para probar rutas y comportamiento similar a un hosting, sirve la carpeta con un servidor HTTP local de confianza.

## Antes de publicar

- reemplazar cualquier dato de contacto de ejemplo por información confirmada;
- revisar navegación, títulos, metadatos, favicon y URL canónica;
- optimizar imágenes y añadir tamaños responsivos;
- validar HTML, CSS, accesibilidad, móvil y enlaces;
- confirmar derechos de uso de textos e imágenes;
- definir licencia del código y los recursos.

## Contribución y seguridad

Consulta `CONTRIBUTING.md`, `SECURITY.md` y `AGENTS.md` antes de modificar el sitio.
